{% trans "📅 Cómo suscribirte al calendario" %}

Google Calendar

  1. {% trans 'Copia la URL de suscripción (botón "Copiar" arriba)' %}
  2. {% trans "Abre" %} Google Calendar
  3. {% blocktrans %}En la barra lateral izquierda, busca "Otros calendarios" y haz clic en el +{% endblocktrans %}
  4. {% blocktrans %}Selecciona "Desde URL"{% endblocktrans %}
  5. {% blocktrans %}Pega la URL copiada y haz clic en "Agregar calendario"{% endblocktrans %}
  6. {% trans "¡Listo! Los partidos aparecerán automáticamente 🎉" %}

Apple Calendar (iPhone/Mac)

  1. {% trans "Copia la URL de suscripción" %}
  2. {% blocktrans %}En iPhone/iPad: Ve a Ajustes → Calendario → Cuentas → Añadir cuenta → Otra → Añadir calendario por suscripción{% endblocktrans %}
  3. {% blocktrans %}En Mac: Abre Calendar → Archivo → Nueva suscripción a calendario{% endblocktrans %}
  4. {% blocktrans %}Pega la URL y haz clic en "Suscribirse"{% endblocktrans %}
  5. {% trans "Configura la frecuencia de actualización (recomendado: cada 12 horas o diariamente)" %}
  6. {% trans "¡Listo! Los partidos se sincronizarán automáticamente 🎉" %}

Outlook / Outlook.com

  1. {% trans "Copia la URL de suscripción" %}
  2. {% trans "Abre" %} Outlook Calendar
  3. {% blocktrans %}Haz clic en "Agregar calendario" en la barra lateral{% endblocktrans %}
  4. {% blocktrans %}Selecciona "Suscribirse desde web"{% endblocktrans %}
  5. {% trans "Pega la URL y dale un nombre al calendario" %}
  6. {% blocktrans %}Haz clic en "Importar"{% endblocktrans %}
  7. {% trans "¡Listo! Los eventos se actualizarán automáticamente 🎉" %}

{% trans "⚠️ Notas importantes:" %}

  • {% blocktrans %}Privacidad: La URL es única y personal. No la compartas.{% endblocktrans %}
  • {% blocktrans %}Actualizaciones: Los calendarios se actualizan cada 12 horas aproximadamente (configurable en tu app de calendario).{% endblocktrans %}
  • {% blocktrans %}Cambios de categorías: Si cambias tus categorías preferidas, el calendario se actualizará automáticamente en la siguiente sincronización.{% endblocktrans %}
  • {% blocktrans %}Solo lectura: No puedes editar los eventos desde tu calendario, son solo de consulta.{% endblocktrans %}
