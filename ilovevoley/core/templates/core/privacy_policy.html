{% trans "Política de Privacidad" %}

{% trans "Información sobre el tratamiento de datos y protección de la imagen en la plataforma comunitaria" %}

{% icon 'lock' %} {% trans "1. Responsable del Tratamiento" %}

{% blocktrans trimmed %} Esta plataforma es un entorno comunitario, familiar y deportivo, gestionado por familias y sin ánimo de lucro ni actividad económica. El acceso al contenido está restringido a miembros y familias autorizadas del club. {% endblocktrans %}

{% blocktrans trimmed with email=privacy_email %} Para cualquier consulta, solicitud o ejercicio de derechos relativos a tus datos personales o imágenes, puedes contactar con el responsable a través de la dirección de correo electrónico: {{ email }}. {% endblocktrans %}

{% icon 'users' %} {% trans "2. Acceso Restringido y Moderación" %}

{% blocktrans trimmed %} La plataforma no es un servicio abierto al público indiscriminado. Cada solicitud de registro requiere verificación y aprobación manual por parte de los coordinadores o administradores del club, con el fin de confirmar la vinculación familiar o deportiva con el club y garantizar un entorno seguro y de confianza para todos los participantes, especialmente menores de edad. {% endblocktrans %}

{% icon 'info' %} {% trans "3. Datos Tratados y su Procedencia" %}

{% trans "Tratamos únicamente los datos necesarios para la gestión comunitaria y deportiva del club:" %}

  • {% trans "Datos de cuenta y registro:" %} {% trans "Nombre de usuario, dirección de correo electrónico y la información de parentesco o vinculación familiar facilitada al solicitar el alta." %}
  • {% trans "Fichas y datos deportivos:" %} {% trans "Nombre y apellidos de deportistas y cuerpo técnico, año o fecha de nacimiento, dorsal, equipo, club y categoría, así como datos de partidos y actas oficiales provenientes de las competiciones federativas." %}
  • {% trans "Fotografías y vídeos:" %} {% trans "Imágenes y grabaciones de encuentros, entrenamientos y actividades deportivas compartidas por familias, entrenadores y socios para el seguimiento de la temporada." %}

{% icon 'check' %} {% trans "4. Finalidad y Base Jurídica" %}

{% blocktrans trimmed %} La finalidad del tratamiento es exclusivamente la coordinación deportiva, la difusión privada de partidos y momentos de los equipos, y el fomento de la comunidad entre las familias del voleibol. {% endblocktrans %}

{% blocktrans trimmed %} La base jurídica que legitima este tratamiento es el consentimiento otorgado al registrarse y en las fichas del club, así como el interés legítimo de la comunidad deportiva en organizar sus actividades sin fines comerciales. No se ceden datos a terceros para publicidad, comercialización ni perfiles de marketing. {% endblocktrans %}

{% icon 'eye' %} {% trans "5. Protección de Menores y Revisión Automatizada de Imágenes" %}

{% blocktrans trimmed %} Con el objetivo primordial de proteger a los menores de edad y asegurar que no se difunda contenido inapropiado, ilícito o perjudicial, las imágenes subidas a la plataforma pueden ser analizadas de manera automatizada mediante la tecnología de Google Cloud Vision API (SafeSearch). {% endblocktrans %}

{% blocktrans trimmed %} Este análisis se limita de forma estricta a la detección preventiva de contenidos no aptos o inadecuados para menores. Las imágenes no se utilizan para entrenamiento de modelos comerciales ni se asocian a perfiles individuales de usuarios. {% endblocktrans %}

{% icon 'camera' %} {% trans "6. Consentimiento de Imagen y Derecho de Retirada" %}

{% blocktrans trimmed %} Reconocemos y respetamos el derecho a la propia imagen de cada deportista y de sus tutores legales: {% endblocktrans %}

{% trans "Preferencia de imagen en la ficha:" %} {% trans "El sistema permite registrar en la ficha deportiva si existe consentimiento de imagen para la difusión de fotografías del jugador o jugadora." %}

{% trans "Solicitud directa de retirada de fotos:" %} {% blocktrans trimmed with email=privacy_email %} Cualquier familia o deportista puede solicitar en cualquier momento la retirada de una fotografía en la que aparezca, tanto utilizando el botón de solicitud de retirada disponible en la propia foto como enviando un mensaje a {{ email }}. La solicitud será atendida y procesada por los moderadores del club de forma prioritaria. {% endblocktrans %}

{% icon 'cog' %} {% trans "7. Cookies y Almacenamiento Local" %}

{% blocktrans trimmed %} Esta web utiliza exclusivamente cookies técnicas necesarias para su funcionamiento: {% endblocktrans %}

  • {% trans "Cookies de sesión y seguridad (Django):" %} {% trans "Imprescindibles para mantener la sesión de usuario activa y proteger los formularios frente a ataques de falsificación (CSRF). Se eliminan al cerrar el navegador o al expirar la sesión." %}
  • {% trans "Cookies de autenticación (Google OAuth):" %} {% trans "Necesarias únicamente si el usuario elige iniciar sesión con su cuenta de Google, gestionadas de acuerdo con la autenticación segura del proveedor." %}

{% trans "No utilizamos cookies publicitarias, rastreadores entre sitios ni herramientas de analítica intrusiva." %}

{% icon 'document' %} {% trans "8. Conservación de Datos y Derechos RGPD" %}

{% blocktrans trimmed %} Los datos se conservan durante el tiempo en que la cuenta de usuario permanezca activa y durante las temporadas deportivas en las que el deportista participe en las actividades del club, o hasta que se solicite su supresión. {% endblocktrans %}

{% blocktrans trimmed with email=privacy_email %} En virtud del RGPD, tienes derecho a acceder a tus datos, rectificar aquellos inexactos, solicitar su supresión ("derecho al olvido"), limitar u oponerte a su tratamiento, y revocar en cualquier momento el consentimiento prestado. Para ejercer cualquiera de estos derechos, basta con enviar un correo electrónico a {{ email }} indicando tu solicitud. {% endblocktrans %}
